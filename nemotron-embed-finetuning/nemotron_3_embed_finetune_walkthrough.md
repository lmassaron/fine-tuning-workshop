# Fine-Tuning NVIDIA Nemotron-3 Embedding Model with Hugging Face & Sentence-Transformers

This walkthrough details the step-by-step workflow in [`nemotron_3_embed_finetune_hf.ipynb`](file:///home/lmassaron/code/sft-examples/nemotron-embed-finetuning/nemotron_3_embed_finetune_hf.ipynb) for fine-tuning `nvidia/Nemotron-3-Embed-1B-BF16` on domain-specific documentation using synthetic data generation and Parameter-Efficient Fine-Tuning (LoRA).

---

## 📌 Overview & Objective

The goal of this notebook is to adapt an NVIDIA Nemotron embedding model for domain-specific document retrieval (e.g., technical documentation) without requiring manually annotated Query-Document pairs.

### Key Highlights
- **Synthetic Data Generation**: Uses `Qwen/Qwen2.5-1.5B-Instruct` (quantized to 4-bit) to auto-generate high-quality synthetic questions (anchors) from raw document chunks (positives).
- **LoRA Fine-Tuning**: Applies Low-Rank Adaptation (LoRA) to target projection matrices (`all-linear`) of `nvidia/Nemotron-3-Embed-1B-BF16`.
- **Metric Learning Loss**: Uses `MultipleNegativesRankingLoss` (MNRL) for contrastive retrieval learning using in-batch negatives.
- **Evaluation**: Evaluates retrieval accuracy using strict **Recall@1** by comparing similarity matrices before and after fine-tuning.

### 3. Synthetic Query Generation (`Qwen2.5-1.5B-Instruct`)
To generate training pairs without manual annotation, a 4-bit quantized instruction-tuned LLM (`Qwen/Qwen2.5-1.5B-Instruct`) is loaded:

```python
qwen_bnb = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_compute_dtype=torch.bfloat16)
llm_model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-1.5B-Instruct", quantization_config=qwen_bnb, device_map="auto"
)
```

#### Chunking & Question Prompting
The function `generate_synthetic_pair` extracts a text chunk (~1,500 characters) and prompts Qwen:
> *"Read the following document chunk and generate a single, short, specific question that is directly answered by it."*

Each output forms an `(anchor, positive)` pair:
- **`anchor`**: Synthetic query generated by Qwen.
- **`positive`**: Original document text chunk.

---

### 4. Dataset Preparation & Train/Eval Split
```python
pair_ds = sample_ds.map(generate_synthetic_pair, remove_columns=sample_ds.column_names)
split_ds = pair_ds.train_test_split(test_size=0.2, seed=42)
train_ds = split_ds["train"]
eval_ds  = split_ds["test"]
```
The resulting pair dataset is split into **80% Training** and **20% Evaluation** sets (seed 42).

### 5. Base Embedding Model & LoRA Adapter Configuration
The base model `nvidia/Nemotron-3-Embed-1B-BF16` is wrapped in `SentenceTransformer` with `bfloat16` precision.

```python
embed_model = SentenceTransformer("nvidia/Nemotron-3-Embed-1B-BF16", model_kwargs={"dtype": torch.bfloat16})

lora_config = LoraConfig(
    r=8,
    lora_alpha=16,
    target_modules="all-linear",
    lora_dropout=0.05,
    bias="none",
    task_type=TaskType.FEATURE_EXTRACTION,
)
```
- **Rank (`r`)**: 8
- **Alpha (`lora_alpha`)**: 16
- **Target Modules**: `"all-linear"` (targets all linear projections in the transformer backbone)
- **Trainable Parameters**: `2,097,152` out of `1,143,015,424` total parameters (**0.1835%** trainable)

---

### 6. Fine-Tuning with `SentenceTransformerTrainer`

```python
loss = MultipleNegativesRankingLoss(embed_model)

args = SentenceTransformerTrainingArguments(
    output_dir="./nemotron-embed-finetuned",
    num_train_epochs=1,
    per_device_train_batch_size=2,
    per_device_eval_batch_size=2,
    learning_rate=2e-4,
    bf16=True,
    logging_steps=50,
    save_strategy="no",
    report_to="none",
)

trainer = SentenceTransformerTrainer(
    model=embed_model, args=args, train_dataset=train_ds, loss=loss
)
trainer.train()
```
- **Loss Function**: `MultipleNegativesRankingLoss` treats other document samples in the mini-batch as negative examples for each query anchor.
- **Precision**: `bf16` enabled for fast GPU compute.

---

### 7. Evaluation & Strict Recall@1 Comparison

The performance is evaluated on the 20% test set using cosine similarity matrix computation:

```python
def evaluate_retrieval(model, model_name):
    query_embs = model.encode(eval_queries)
    doc_embs = model.encode(eval_docs)
    similarities = np.dot(query_embs, doc_embs.T)
    top_doc_indices = np.argmax(similarities, axis=1)
    correct_indices = np.arange(len(eval_queries))
    recall_at_1 = np.sum(top_doc_indices == correct_indices) / len(eval_queries)
    print(f"{model_name} Strict Recall@1: {recall_at_1 * 100:.2f}%")
    return recall_at_1
```

#### Benchmark Results:
- **Original Model (`nvidia/Nemotron-3-Embed-1B-BF16`)**: **33.17%** Strict Recall@1
- **Fine-Tuned Model (LoRA Adapter)**: **73.67%** Strict Recall@1
- **Absolute Improvement**: **+40.50%** boost in retrieval accuracy after fine-tuning.
